# Руководство по работе с индивидуальными заданиями

## Обзор системы

Система индивидуальных заданий в MathBot позволяет учителям создавать и отправлять задания ученикам, а ученикам - выполнять их и получать оценки. Система поддерживает полный цикл работы с заданиями от создания до проверки.

## Для учителей

### Управление учащимися

#### 1. Прикрепить класс
- **Команда**: `Прикрепить класс`
- **Процесс**:
  1. Введите имя ученика для поиска
  2. Система найдет всех учеников с похожими именами
  3. Выберите нужного ученика из списка результатов
  4. Ученик будет прикреплен к вам как учителю
  5. Теперь вы можете отправлять ему индивидуальные задания

**Примечание**: Поиск работает по частичному совпадению имени (регистр не учитывается). Если ученик не найден, убедитесь, что он зарегистрирован в системе.

#### 2. Просмотр прикрепленных учеников
- **Команда**: `Ваши учащиеся`
- **Отображает**:
  - Список всех прикрепленных к вам учеников
  - Возможность отправки индивидуальных заданий

### Создание и отправка заданий

#### 1. Отправка индивидуального задания
- **Команда**: `Отправить индивидуальное задание`
- **Процесс**:
  1. Выберите ученика из списка ваших учащихся
  2. Выберите тему: "Алгебра" или "Геометрия"
  3. Выберите сложность: "Легкая", "Средняя" или "Сложная"
  4. Система автоматически сгенерирует задание с помощью ИИ
  5. Задание будет отправлено ученику

#### 2. Просмотр отправленных заданий
- **Команда**: `Мои задания`
- **Отображает**:
  - Список всех отправленных заданий
  - Статус каждого задания
  - Кнопки для проверки выполненных заданий

#### 3. Проверка ответов учеников
- **Доступно для заданий со статусом "completed"**
- **Процесс**:
  1. Нажмите "Проверить ответ #ID"
  2. Просмотрите задание и ответ ученика
  3. Выберите оценку: "Отлично", "Хорошо", "Удовлетворительно", "Неудовлетворительно"
  4. Введите комментарий/обратную связь
  5. Система сохранит оценку и обновит статус

### Статусы заданий для учителей
- **"sent"** - Задание отправлено ученику
- **"completed"** - Ученик выполнил задание (требует проверки)
- **"graded"** - Задание проверено и оценено

## Для учеников

### Управление учителями

#### 1. Прикрепиться к учителю
- **Процесс**: Учитель должен использовать команду "Прикрепить класс" и найти вас по имени
- **Результат**: После прикрепления вы сможете получать задания от этого учителя
- **Проверка**: Используйте команду "Мои учителя" для просмотра списка прикрепленных учителей

### Получение и выполнение заданий

#### 1. Просмотр полученных заданий
- **Команда**: `Мои задания`
- **Отображает**:
  - Список всех полученных заданий
  - Статус каждого задания
  - Кнопки для выполнения заданий

#### 2. Выполнение задания
- **Доступно для заданий со статусом "sent"**
- **Процесс**:
  1. Нажмите "Отправить ответ #ID"
  2. Просмотрите задание
  3. Введите ваш ответ в текстовом формате
  4. Система сохранит ответ и обновит статус

#### 3. Просмотр оценок
- **Доступно для заданий со статусом "graded"**
- **Отображает**:
  - Оценку учителя
  - Комментарий/обратную связь
  - Дату проверки

#### 4. Тест-викторина
- **Команда**: `Тест-викторина`
- **Процесс**:
  1. Выберите тему: "Алгебра", "Геометрия", "Тригонометрия" или "Арифметика"
  2. Выберите сложность: "Легкая", "Средняя" или "Сложная"
  3. Система автоматически сгенерирует тест-викторину с помощью ИИ
  4. Отвечайте на 5 заданий по одному (каждое содержит 3 утверждения)
  5. Введите ответы, используя цифры 1, 2, 3 (например: 1, 12, 23, 123)
  6. Получите подробный отчет с результатами и оценкой

**Особенности тест-викторины:**
- Каждое задание содержит 3 утверждения
- Можно выбрать одно или несколько правильных утверждений
- Автоматическая проверка ответов
- Детальный анализ результатов с процентным соотношением
- Оценка по 4-балльной шкале (Отлично, Хорошо, Удовлетворительно, Требует доработки)

### Статусы заданий для учеников
- **"sent"** - Задание получено (требует выполнения)
- **"completed"** - Задание выполнено (ожидает проверки)
- **"graded"** - Задание проверено (можно посмотреть оценку)

## Технические детали

### База данных
Таблица `singly_assigment` содержит следующие поля:
- **Основные**: `id`, `sender_id`, `recipient_id`
- **Задание**: `task_text`, `topic`, `difficulty`, `status`
- **Временные метки**: `created_at`, `deadline`
- **Ответы и оценки**: `student_answer`, `answer_submitted_at`, `teacher_feedback`, `grade`, `graded_at`

### Генерация заданий
Задания генерируются автоматически с помощью ИИ (OpenAI) на основе:
- Выбранной темы (алгебра/геометрия)
- Уровня сложности
- Предустановленных шаблонов для каждого типа

## Рекомендации по использованию

### Для учителей
1. **Регулярно проверяйте** статус "completed" заданий
2. **Давайте конструктивную обратную связь** при оценке
3. **Используйте разные уровни сложности** для дифференцированного обучения
4. **Отслеживайте прогресс** учеников через систему заданий

### Для учеников
1. **Своевременно выполняйте** полученные задания
2. **Внимательно читайте** комментарии учителя
3. **Используйте систему** для самопроверки знаний
4. **Обращайтесь к учителю** при возникновении вопросов

## Поддержка

При возникновении проблем с системой заданий:
1. Проверьте статус бота
2. Убедитесь в корректности вводимых данных
3. Обратитесь к администратору системы
