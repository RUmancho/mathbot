# 🎓 Демо-сценарии для учеников - MathBot

## 📚 Обзор возможностей для учеников

MathBot предоставляет ученикам мощные инструменты для изучения математики, включая доступ к теоретическим материалам, выполнение индивидуальных заданий от учителей, участие в тест-викторинах и многое другое.

---

## 🎯 Демо-сценарий 1: Изучение теоретических материалов

### 🎬 Сценарий демонстрации:
1. **Регистрация как ученик**
   - Пользователь отправляет `/start`
   - Выбирает роль "Ученик"
   - Вводит свои данные (имя, город, школа, класс)

2. **Доступ к теоретическим материалам**
   - Нажимает кнопку "📚 Теория"
   - Выбирает раздел математики (например, "Алгебра")
   - Выбирает конкретную тему (например, "Квадратные уравнения")
   - Получает подробное объяснение с примерами

### ✨ Ключевые особенности:
- **Структурированные материалы** по разделам математики
- **Пошаговые объяснения** сложных тем
- **Практические примеры** для лучшего понимания
- **Удобная навигация** по темам

---

## 🎯 Демо-сценарий 2: Выполнение индивидуального задания от учителя

### 🎬 Сценарий демонстрации:
1. **Получение задания**
   - Учитель отправляет индивидуальное задание по теме "Алгебра"
   - Ученик нажимает "📋 Получить задания"
   - Видит список своих заданий с полным текстом

2. **Выполнение задания**
   - Нажимает "✍️ Ответить #ID" на конкретном задании
   - Читает задание полностью
   - Отправляет свой ответ в текстовом виде

3. **Получение оценки**
   - Учитель проверяет и оценивает работу
   - Ученик получает оценку и обратную связь
   - Может просмотреть все свои оценки

### ✨ Ключевые особенности:
- **Персонализированные задания** от учителя
- **LLM-генерация** заданий по выбранной теме и сложности
- **Простая отправка ответов** в текстовом формате
- **Система оценок** с подробной обратной связью
- **Отслеживание прогресса** по всем заданиям

---

## 🎯 Демо-сценарий 3: Участие в тест-викторине

### 🎬 Сценарий демонстрации:
1. **Запуск викторины**
   - Нажимает "🎯 Тест-викторина"
   - Выбирает тему (например, "Геометрия")
   - Выбирает уровень сложности (например, "Средний")

2. **Прохождение теста**
   - LLM генерирует уникальный тест с 5 вопросами
   - Каждый вопрос имеет 4 варианта ответа
   - Ученик выбирает ответы по очереди

3. **Получение результатов**
   - Система подсчитывает правильные ответы
   - Показывает процент успешности
   - Дает мотивационное сообщение

### ✨ Ключевые особенности:
- **AI-генерация** уникальных тестов каждый раз
- **Адаптивная сложность** (легкий, средний, сложный)
- **Множественный выбор** ответов
- **Мгновенная проверка** результатов
- **Разнообразие тем** и вопросов

---

## 🎯 Демо-сценарий 4: Поиск и прикрепление к учителю

### 🎬 Сценарий демонстрации:
1. **Поиск учителя**
   - Нажимает "🔍 Найти учителя"
   - Вводит город (например, "Нижний Новгород")
   - Вводит номер школы
   - Вводит номер класса

2. **Просмотр результатов**
   - Видит список найденных учителей
   - Выбирает "Прикрепить всех" для автоматического прикрепления
   - Получает подтверждение успешного прикрепления

### ✨ Ключевые особенности:
- **Умный поиск** по городу, школе и классу
- **Unicode-совместимый** поиск (поддержка кириллицы)
- **Автоматическое прикрепление** к учителям
- **Быстрая навигация** по результатам поиска

## 🎯 Демо-сценарий 5: Работа с математическими ресурсами

### 🎬 Сценарий демонстрации:
1. **Доступ к ресурсам**
   - Нажимает "📖 Ресурсы"
   - Выбирает интересующий раздел математики
   - Получает доступ к файлам и материалам

2. **Изучение материалов**
   - Просматривает формулы и правила
   - Изучает примеры решения задач
   - Осваивает новые методы

### ✨ Ключевые особенности:
- **Богатая библиотека** математических материалов
- **Структурированный доступ** к ресурсам
- **Практические примеры** и решения
- **Постоянное обновление** контента
