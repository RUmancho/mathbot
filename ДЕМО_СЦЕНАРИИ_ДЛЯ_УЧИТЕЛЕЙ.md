# 👨‍🏫 Демо-сценарии для учителей - MathBot

## 📚 Обзор возможностей для учителей

MathBot предоставляет учителям мощные инструменты для управления учебным процессом, включая создание AI-генерируемых заданий, проверку работ учеников, проведение тест-викторин и эффективное управление классом.

---

## 🎯 Демо-сценарий 1: Регистрация и настройка профиля

### 🎬 Сценарий демонстрации:
1. **Первичная регистрация**
   - Пользователь отправляет `/start`
   - Выбирает роль "Учитель"
   - Вводит свои данные (имя, город, школа, предмет)

2. **Настройка профиля**
   - Система автоматически создает профиль учителя
   - Профиль становится доступным для поиска учениками
   - Учитель может управлять своими данными

### ✨ Ключевые особенности:
- **Быстрая регистрация** в несколько кликов
- **Автоматическое создание** профиля
- **Готовность к работе** сразу после регистрации
- **Профессиональный статус** в системе

---

## 🎯 Демо-сценарий 2: Поиск и прикрепление учеников

### 🎬 Сценарий демонстрации:
1. **Поиск учеников**
   - Нажимает "🔍 Найти ученика"
   - Вводит город (например, "Москва")
   - Вводит номер школы
   - Вводит номер класса

2. **Просмотр результатов**
   - Система показывает список найденных учеников
   - Отображает информацию о каждом ученике
   - Предлагает варианты действий

3. **Прикрепление учеников**
   - Выбирает "Прикрепить всех" для массового прикрепления
   - Получает подтверждение успешного прикрепления
   - Ученики автоматически добавляются в список

### ✨ Ключевые особенности:
- **Умный поиск** с поддержкой кириллицы
- **Фильтрация** по городу, школе и классу
- **Массовое прикрепление** учеников
- **Автоматическое управление** списком класса

---

## 🎯 Демо-сценарий 3: Создание и отправка индивидуальных заданий

### 🎬 Сценарий демонстрации:
1. **Запуск создания задания**
   - Нажимает "📝 Отправить задание"
   - Выбирает "Отправить индивидуальное задание"
   - Система показывает список прикрепленных учеников

2. **Выбор параметров**
   - Выбирает конкретного ученика из списка
   - Выбирает тему (например, "Алгебра", "Геометрия")
   - Выбирает уровень сложности (легкий, средний, сложный)

3. **Генерация и отправка**
   - LLM автоматически генерирует уникальное задание
   - Учитель просматривает сгенерированное задание
   - Подтверждает отправку ученику

### ✨ Ключевые особенности:
- **AI-генерация** заданий по выбранным параметрам
- **Персонализация** для каждого ученика
- **Гибкие настройки** сложности и темы
- **Мгновенная отправка** ученикам
- **Автоматическое сохранение** в базе данных

---

## 🎯 Демо-сценарий 4: Проверка и оценка работ учеников

### 🎬 Сценарий демонстрации:
1. **Просмотр выполненных работ**
   - Нажимает "📋 Мои задания"
   - Видит список всех отправленных заданий
   - Отмечает задания, готовые к проверке

2. **Проверка работы**
   - Нажимает "✍️ Проверить #ID" на конкретном задании
   - Читает ответ ученика
   - Оценивает работу по 5-балльной шкале

3. **Написание отзыва**
   - Пишет подробный отзыв к работе
   - Дает рекомендации по улучшению
   - Отправляет оценку и отзыв ученику

### ✨ Ключевые особенности:
- **Централизованное управление** всеми заданиями
- **Удобная система** проверки и оценки
- **Детальная обратная связь** для учеников
- **Отслеживание прогресса** каждого ученика
- **Профессиональный подход** к оцениванию

## 🎯 Демо-сценарий 5: Управление классом и мониторинг

### 🎬 Сценарий демонстрации:
1. **Просмотр списка учеников**
   - Нажимает "👥 Ваши учащиеся"
   - Видит полный список прикрепленных учеников
   - Получает информацию о статусе каждого

2. **Анализ активности**
   - Просматривает статистику выполнения заданий
   - Отслеживает прогресс учеников
   - Планирует дальнейшую работу

3. **Управление классом**
   - Добавляет новых учеников при необходимости
   - Удаляет учеников из списка при необходимости
   - Поддерживает актуальный состав класса

### ✨ Ключевые особенности:
- **Полный контроль** над составом класса
- **Мониторинг активности** учеников
- **Гибкое управление** списком учащихся
- **Статистическая информация** по классу
